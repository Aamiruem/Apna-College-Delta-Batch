Here’s a clear, structured explanation of handling deletion in computing and data management, covering the key concepts, methods, and considerations.

1. What Does “Handling Deletion” Mean?
Handling deletion refers to the processes, policies, and mechanisms used to remove data or resources from a system, while maintaining consistency, performance, security, and recovery options.

2. Types of Deletion
Type	Description	Recovery Possible?
Logical Deletion	Mark data as deleted (e.g., flag is_deleted = true) without physically removing it.	Yes (unset flag)
Physical Deletion	Actually remove data from storage medium.	Usually no (unless backups)
Soft Deletion	Data hidden from regular queries but kept for audit or restore.	Yes
Hard Deletion	Permanent removal of data/records.	No (except backups)
Cascading Deletion	Deleting a parent record automatically deletes dependent children.	No (unless backed up)
3. Common Scenarios & Handling Strategies
a) Database Row Deletion
Soft delete: Add deleted_at timestamp column. Queries filter by deleted_at IS NULL.

Hard delete: DELETE FROM table WHERE id = ?.

Cascade: Use foreign key ON DELETE CASCADE.

b) File Deletion
Move to recycle bin / trash first (logical).

Empty trash = physical deletion (but data may remain until overwritten).

Secure deletion: overwrite with random data (e.g., shred on Linux).

c) Cache Deletion
Explicit eviction: Remove specific keys.

TTL (Time-To-Live) : Automatic deletion after expiry.

Cache invalidation on data update.

d) User Account Deletion (GDPR, privacy laws)
Anonymization instead of deletion (remove PII).

Right to be forgotten: Delete or anonymize after retention period.

Soft deletion first, then hard deletion after 30-day grace period.

4. Key Considerations in Deletion Handling
Consideration	Explanation
Consistency	Deleting related data to avoid orphaned records.
Performance	Hard deletes may be slow on large tables; soft deletes can lead to bloat.
Recovery & Backup	Ensure backups exist before hard deletes.
Security	Prevent unauthorized deletion. Use permissions and logs.
Audit & Compliance	Keep deletion logs for legal reasons (e.g., who deleted what and when).
User Experience	Provide undo/restore options (soft delete + trash).
5. Example: Soft Delete vs Hard Delete in Code (SQL & Pseudo)
Soft Delete

sql
ALTER TABLE users ADD deleted_at TIMESTAMP NULL;

-- Soft delete
UPDATE users SET deleted_at = NOW() WHERE id = 123;

-- Query active users
SELECT * FROM users WHERE deleted_at IS NULL;
Hard Delete

sql
DELETE FROM users WHERE id = 123;
6. Best Practices Summary
Use soft delete for user-facing data that may need recovery.

Use hard delete for temporary or non-critical data.

Enforce cascading deletion carefully to avoid accidental data loss.

Always back up before bulk deletions.

Log deletion events for audit trails.

Implement confirmation dialogs in UIs for irreversible actions.

Mongoose Middleware - Complete Guide
Mongoose middleware (also called pre and post hooks) are functions that execute at specific points in the lifecycle of a database operation.

1. Types of Middleware
Type	Description	Execution
Pre-middleware	Runs before an operation	Can modify documents/query, abort operation
Post-middleware	Runs after an operation	Access the result, no modification possible
Error-handling middleware	Catches errors	For logging, cleanup, or custom error handling
2. Middleware Execution Points
Document Middleware
Runs on individual document instances:

javascript
// Available hooks
userSchema.pre('validate', function(next) { ... });    // Before validation
userSchema.pre('save', function(next) { ... });        // Before saving
userSchema.pre('remove', function(next) { ... });      // Before removing
userSchema.pre('updateOne', function(next) { ... });   // Before update

// Post hooks
userSchema.post('save', function(doc, next) { ... });
userSchema.post('remove', function(doc, next) { ... });
Query Middleware
Runs on query operations:

javascript
// Pre query hooks
userSchema.pre('find', function(next) { ... });
userSchema.pre('findOne', function(next) { ... });
userSchema.pre('findOneAndUpdate', function(next) { ... });
userSchema.pre('findOneAndDelete', function(next) { ... });
userSchema.pre('updateMany', function(next) { ... });
userSchema.pre('deleteMany', function(next) { ... });

// Post query hooks
userSchema.post('find', function(docs, next) { ... });
userSchema.post('findOneAndDelete', function(doc, next) { ... });
Aggregate Middleware
Runs on aggregation pipelines:

javascript
userSchema.pre('aggregate', function(next) {
  this.pipeline().unshift({ $match: { isActive: true } });
  next();
});

// middleware/authMiddleware.js
const jwt = require('jsonwebtoken');
const User = require('../models/User');

const protect = async (req, res, next) => {
  try {
    let token;

    if (req.headers.authorization && req.headers.authorization.startsWith('Bearer')) {
      token = req.headers.authorization.split(' ')[1];
    }

    if (!token) {
      return res.status(401).json({
        success: false,
        message: 'Not authorized, no token'
      });
    }

    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = await User.findById(decoded.id).select('-password');
    
    next();
  } catch (error) {
    res.status(401).json({
      success: false,
      message: 'Not authorized, token failed'
    });
  }
};

const getProductReviews = async (req, res) => {
  try {

      page = 1, 
      limit = 10, 
      sortBy = 'newest',
      rating,
      hasImages,
      isRecommended,
      status = 'approved'
    } = req.query;

    // Build query
    let query = { 
      product: productId,
      status: status
    };
    
    if (rating) query.rating = parseInt(rating);
    if (hasImages === 'true') query['images.0'] = { $exists: true };
    if (isRecommended) query.isRecommended = isRecommended === 'true';

    // Sorting logic
    let sort = {};
    switch(sortBy) {
      case 'newest':
        sort = { createdAt: -1 };
        break;
      case 'oldest':
        sort = { createdAt: 1 };
        break;
      case 'highest':
        sort = { rating: -1 };
        break;
      case 'lowest':
        sort = { rating: 1 };
        break;
      case 'helpful':
        sort = { 'helpfulVotes.count': -1 };
        break;
      default:
        sort = { createdAt: -1 };
    }

    // Pagination
    const pageNum = parseInt(page);
    const limitNum = parseInt(limit);
    const skip = (pageNum - 1) * limitNum;

    // Execute query
    const reviews = await Review.find(query)
      .populate('user', 'name avatar')
      .populate('adminResponse.respondedBy', 'name')
      .sort(sort)
      .limit(limitNum)
      .skip(skip);

    const total = await Review.countDocuments(query);

    // Get rating statistics
    const stats = await Review.aggregate([
      {
        $match: { 
          product: mongoose.Types.ObjectId(productId),
          status: 'approved'
        }
      },
      {
        $group: {
          _id: null,
          averageRating: { $avg: '$rating' },
          totalReviews: { $sum: 1 },
          ratingDistribution: {
            $push: '$rating'
          }
        }
      }
    ]);

    // Get helpful reviews count
    const helpfulStats = await Review.aggregate([
      {
        $match: { 
          product: mongoose.Types.ObjectId(productId),
          status: 'approved'
        }
      },
      {
        $group: {
          _id: null,
          totalHelpfulVotes: { $sum: '$helpfulVotes.count' }
        }
      }
    ]);

    res.status(200).json({
      success: true,
      data: reviews,
      stats: {
        averageRating: stats[0]?.averageRating?.toFixed(1) || 0,
        totalReviews: stats[0]?.totalReviews || 0,
        totalHelpfulVotes: helpfulStats[0]?.totalHelpfulVotes || 0
      },
      pagination: {
        page: pageNum,
        limit: limitNum,
        total,
        pages: Math.ceil(total / limitNum)
      }
    });

    res.status(400).json({

            success: false,
            message: 'Each image must be less than 5MB'
          });
        }
        
        images.push({
          url: file.path,
          publicId: file.filename,
          caption: ''
        });
      }
    }
    
    // Create review
    const review = new Review({
      rating,
      title,
      comment,
      user: userId,
      product: productId,
      isRecommended: isRecommended || false,
      images,
      isVerifiedPurchase: !!order // Mark as verified purchase
    });
    
    await review.save();
    
    res.status(201).json({
      success: true,
      message: 'Review submitted successfully and pending approval',
      data: review
    });
    
  } catch (error) {
    // Handle specific validation errors
    if (error.code === 11000) {
      return res.status(400).json({
        success: false,
        message: 'You have already reviewed this product'
      });
    }
    
    res.status(400).json({
      success: false,
      message: error.message
    });
  }
};

const getProductReviews = async (req, res) => {
  try {
    const { productId } = req.params;
    
    // Validate productId
    if (!mongoose.Types.ObjectId.isValid(productId)) {
      return res.status(400).json({
        success: false,
        message: 'Invalid product ID format'
      });
    }
    
    const { 
      page = 1, 
      limit = 10, 
      minRating, 
      maxRating,
      hasImages,
      sortBy = 'newest'
    } = req.query;
    
    // Validate pagination parameters
    const pageNum = parseInt(page);
    const limitNum = parseInt(limit);
    
    if (isNaN(pageNum) || pageNum < 1) {
      return res.status(400).json({
        success: false,
        message: 'Page must be a positive integer'
      });
    }
    
    if (isNaN(limitNum) || limitNum < 1 || limitNum > 50) {
      return res.status(400).json({
        success: false,
        message: 'Limit must be between 1 and 50'
      });
    }
    
    // Validate rating range
    if (minRating && (minRating < 1 || minRating > 5)) {
      return res.status(400).json({
        success: false,
        message: 'Minimum rating must be between 1 and 5'
      });
    }
    
    if (maxRating && (maxRating < 1 || maxRating > 5)) {
      return res.status(400).json({
        success: false,
        message: 'Maximum rating must be between 1 and 5'
      });
    }
    
    // Build query
    let query = { product: productId, status: 'approved' };
    
    if (minRating || maxRating) {
      query.rating = {};
      if (minRating) query.rating.$gte = parseInt(minRating);
      if (maxRating) query.rating.$lte = parseInt(maxRating);
    }
    
    if (hasImages === 'true') {
      query['images.0'] = { $exists: true };
    }
    
    // Validate sort parameter
    const validSortFields = ['newest', 'oldest', 'highest', 'lowest', 'helpful'];
    if (!validSortFields.includes(sortBy)) {
      return res.status(400).json({
        success: false,
        message: 'Invalid sort parameter'
      });
    }
    
    // Execute query
    const reviews = await Review.find(query)
      .populate('user', 'name avatar')
      .sort(sortBy === 'newest' ? '-createdAt' : 
            sortBy === 'oldest' ? 'createdAt' :
            sortBy === 'highest' ? '-rating' :
            sortBy === 'lowest' ? 'rating' : '-helpfulVotes.count')
      .limit(limitNum)
      .skip((pageNum - 1) * limitNum);
    
    const total = await Review.countDocuments(query);
    
    res.status(200).json({
      success: true,
      data: reviews,
      pagination: {
        page: pageNum,
        limit: limitNum,
        total,
        pages: Math.ceil(total / limitNum)
      }
    });
    
  } catch (error) {
    res.status(400).json({
      success: false,
      message: error.message
    });
  }
};

// components/ReviewForm.jsx
import React, { useState } from 'react';
import { Star, X, Upload } from 'lucide-react';

const ReviewForm = ({ productId, onSubmitSuccess, onCancel }) => {
  const [formData, setFormData] = useState({
    rating: 0,
    title: '',
    comment: '',
    images: [],
    isRecommended: true
  });
  
  const [errors, setErrors] = useState({});
  const [imagePreviews, setImagePreviews] = useState([]);
  const [isSubmitting, setIsSubmitting] = useState(false);
  const [hoverRating, setHoverRating] = useState(0);
  
  // Handle rating click
  const handleRatingClick = (rating) => {
    setFormData(prev => ({ ...prev, rating }));
    setErrors(prev => ({ ...prev, rating: null }));
  };
  
  // Handle text input change
  const handleChange = (e) => {
    const { name, value, type, checked } = e.target;
    setFormData(prev => ({
      ...prev,
      [name]: type === 'checkbox' ? checked : value
    }));
    // Clear error for this field
    if (errors[name]) {
      setErrors(prev => ({ ...prev, [name]: null }));
    }
  };
  
  // Handle image upload
  const handleImageUpload = (e) => {
    const files = Array.from(e.target.files);
    
    if (formData.images.length + files.length > 5) {
      setErrors(prev => ({
        ...prev,
        images: 'Maximum 5 images allowed'
      }));
      return;
    }
    
    // Validate file sizes and types
    const validFiles = files.filter(file => {
      if (!file.type.startsWith('image/')) {
        setErrors(prev => ({
          ...prev,
          images: 'Only image files are allowed'
        }));
        return false;
      }
      if (file.size > 5 * 1024 * 1024) {
        setErrors(prev => ({
          ...prev,
          images: 'Each image must be less than 5MB'
        }));
        return false;
      }
      return true;
    });
    
    setFormData(prev => ({
      ...prev,
      images: [...prev.images, ...validFiles]
    }));
    
    // Create preview URLs
    const previews = validFiles.map(file => URL.createObjectURL(file));
    setImagePreviews(prev => [...prev, ...previews]);
    
    // Clear error
    setErrors(prev => ({ ...prev, images: null }));
  };
  
  // Remove image
  const removeImage = (index) => {
    setFormData(prev => ({
      ...prev,
      images: prev.images.filter((_, i) => i !== index)
    }));
    
    // Revoke object URL to prevent memory leaks
    URL.revokeObjectURL(imagePreviews[index]);
    setImagePreviews(prev => prev.filter((_, i) => i !== index));
  };
  
  // Validate form before submission
  const validateForm = () => {
    const newErrors = {};
    
    if (formData.rating === 0) {
      newErrors.rating = 'Please select a rating';
    }
    
    if (!formData.title.trim()) {
      newErrors.title = 'Title is required';
    } else if (formData.title.length < 3) {
      newErrors.title = 'Title must be at least 3 characters';
    } else if (formData.title.length > 100) {
      newErrors.title = 'Title must be less than 100 characters';
    }
    
    if (!formData.comment.trim()) {
      newErrors.comment = 'Review comment is required';
    } else if (formData.comment.length < 10) {
      newErrors.comment = 'Please provide at least 10 characters';
    } else if (formData.comment.length > 2000) {
      newErrors.comment = 'Comment is too long';
    }
    
    setErrors(newErrors);
    return Object.keys(newErrors).length === 0;
  };
  
  // Handle form submission
  const handleSubmit = async (e) => {
    e.preventDefault();
    
    if (!validateForm()) {
      // Scroll to first error
      const firstError = document.querySelector('.error-message');
      firstError?.scrollIntoView({ behavior: 'smooth', block: 'center' });
      return;
    }
    
    setIsSubmitting(true);
    
    const submitData = new FormData();
    submitData.append('rating', formData.rating);
    submitData.append('title', formData.title);
    submitData.append('comment', formData.comment);
    submitData.append('productId', productId);
    submitData.append('isRecommended', formData.isRecommended);
    
    formData.images.forEach((image, index) => {
      submitData.append('images', image);
    });
    
    try {
      const response = await fetch('/api/reviews', {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${localStorage.getItem('token')}`
        },
        body: submitData
      });
      
      const data = await response.json();
      
      if (response.ok) {
        onSubmitSuccess?.(data.data);
        // Reset form
        setFormData({
          rating: 0,
          title: '',
          comment: '',
          images: [],
          isRecommended: true
        });
        setImagePreviews([]);
      } else {
        setErrors({ submit: data.message });
      }
    } catch (error) {
      setErrors({ submit: 'Failed to submit review. Please try again.' });
    } finally {
      setIsSubmitting(false);
    }
  };
  
  return (
    <div className="review-form-modal">
      <div className="review-form-container">
        <div className="form-header">
          <h2>Write a Review</h2>
          <button className="close-btn" onClick={onCancel}>
            <X size={20} />
          </button>
        </div>
        
        <form onSubmit={handleSubmit}>
          {/* Rating Section */}
          <div className="form-group">
            <label>Your Rating *</label>
            <div className="rating-input">
              {[1, 2, 3, 4, 5].map((star) => (
                <button
                  key={star}
                  type="button"
                  className="star-btn"
                  onClick={() => handleRatingClick(star)}
                  onMouseEnter={() => setHoverRating(star)}
                  onMouseLeave={() => setHoverRating(0)}
                >
                  <Star
                    size={32}
                    fill={(hoverRating || formData.rating) >= star ? '#FFD700' : 'none'}
                    color={(hoverRating || formData.rating) >= star ? '#FFD700' : '#D1D5DB'}
                  />
                </button>
              ))}
            </div>
            {errors.rating && (
              <span className="error-message">{errors.rating}</span>
            )}
          </div>
          
          {/* Title Section */}
          <div className="form-group">
            <label>Review Title *</label>
            <input
              type="text"
              name="title"
              value={formData.title}
              onChange={handleChange}
              placeholder="Summarize your experience"
              maxLength={100}
              className={errors.title ? 'error' : ''}
            />
            <div className="char-counter">
              {formData.title.length}/100 characters
            </div>
            {errors.title && (
              <span className="error-message">{errors.title}</span>
            )}
          </div>
          
          {/* Comment Section */}
          <div className="form-group">
            <label>Your Review *</label>
            <textarea
              name="comment"
              value={formData.comment}
              onChange={handleChange}
              placeholder="What did you like or dislike? (Minimum 10 characters)"
              rows={6}
              maxLength={2000}
              className={errors.comment ? 'error' : ''}
            />
            <div className="char-counter">
              <span className={formData.comment.length < 10 ? 'warning' : ''}>
                {formData.comment.length}/2000 characters
              </span>
              {formData.comment.length < 10 && formData.comment.length > 0 && (
                <span className="hint">Need at least 10 characters</span>
              )}
            </div>
            {errors.comment && (
              <span className="error-message">{errors.comment}</span>
            )}
          </div>
          
          {/* Image Upload Section */}
          <div className="form-group">
            <label>Add Photos (Optional, up to 5)</label>
            <div className="image-upload-area">
              <input
                type="file"
                accept="image/*"
                multiple
                onChange={handleImageUpload}
                id="image-upload"
                style={{ display: 'none' }}
              />
              <label htmlFor="image-upload" className="upload-label">
                <Upload size={24} />
                <span>Click to upload images</span>
                <small>JPG, PNG, WEBP up to 5MB each</small>
              </label>
              
              {imagePreviews.length > 0 && (
                <div className="image-previews">
                  {imagePreviews.map((preview, index) => (
                    <div key={index} className="preview-item">
                      <img src={preview} alt={`Preview ${index + 1}`} />
                      <button
                        type="button"
                        className="remove-image"
                        onClick={() => removeImage(index)}
                      >
                        <X size={16} />
                      </button>
                    </div>
                  ))}
                </div>
              )}
            </div>
            {errors.images && (
              <span className="error-message">{errors.images}</span>
            )}
          </div>
          
          {/* Recommendation Section */}
          <div className="form-group checkbox-group">
            <label>
              <input
                type="checkbox"
                name="isRecommended"
                checked={formData.isRecommended}
                onChange={handleChange}
              />
              Would you recommend this product to others?
            </label>
          </div>
          
          {/* Submit Error */}
          {errors.submit && (
            <div className="submit-error">{errors.submit}</div>
          )}
          
          {/* Form Actions */}
          <div className="form-actions">
            <button type="button" className="cancel-btn" onClick={onCancel}>
              Cancel
            </button>
            <button type="submit" className="submit-btn" disabled={isSubmitting}>
              {isSubmitting ? 'Submitting...' : 'Submit Review'}
            </button>
          </div>
        </form>
      </div>
    </div>
  );
};

export default ReviewForm;

const reviewSchema = new mongoose.Schema({

  },
  
  // NEW: Restoration tracking

    type: Date,
    default: null
  },

    type: mongoose.Schema.Types.ObjectId,
    ref: 'User'
  },
  
  // NEW: Deletion history
  deletionHistory: [{

      type: String,

    },
    performedBy: {
      type: mongoose.Schema.Types.ObjectId,
      ref: 'User'
    },
    reason: String,
    timestamp: {
      type: Date,
      default: Date.now
    }
  }]
  
}, {
  timestamps: true
});

// Indexes for soft delete queries
reviewSchema.index({ isDeleted: 1, createdAt: -1 });
reviewSchema.index({ product: 1, isDeleted: 1 });
reviewSchema.index({ user: 1, isDeleted: 1 });

// Middleware to exclude soft-deleted reviews by default
reviewSchema.pre(/^find/, function(next) {
  // Skip if explicitly asking for deleted reviews
  if (this.getOptions().withDeleted) {
    return next();
  }
  // Filter out soft-deleted reviews
  this.where({ isDeleted: { $ne: true } });
  next();
});

// Static method to include deleted reviews
reviewSchema.statics.findWithDeleted = function() {
  return this.find().setOptions({ withDeleted: true });
};

// Method to soft delete
reviewSchema.methods.softDelete = async function(userId, reason, comment = '') {
  this.isDeleted = true;
  this.deletedAt = new Date();
  this.deletedBy = userId;
  this.deleteReason = reason;
  this.deleteComment = comment;
  
  this.deletionHistory.push({
    action: 'deleted',
    performedBy: userId,
    reason: comment,
    timestamp: new Date()
  });
  
  await this.save();
  
  // Update product rating
  await this.constructor.calculateAverageRating(this.product);
  
  return this;
};

// Method to restore soft-deleted review
reviewSchema.methods.restore = async function(userId) {
  this.isDeleted = false;
  this.deletedAt = null;
  this.deletedBy = null;
  this.deleteReason = null;
  this.restoredAt = new Date();
  this.restoredBy = userId;
  
  this.deletionHistory.push({
    action: 'restored',
    performedBy: userId,
    timestamp: new Date()
  });
  
  await this.save();
  
  // Update product rating
  await this.constructor.calculateAverageRating(this.product);
  
  return this;
};

// Method to hard delete (permanent)
reviewSchema.methods.hardDelete = async function(userId) {
  this.deletionHistory.push({
    action: 'hard_deleted',
    performedBy: userId,
    timestamp: new Date()
  });
  
  // Store deletion record before removing
  const DeletionLog = mongoose.model('DeletionLog');
  await DeletionLog.create({
    originalId: this._id,
    reviewData: this.toObject(),
    deletedBy: userId,
    deletedAt: new Date()
  });
  
  await this.remove();
};

module.exports = mongoose.model('Review', reviewSchema);

// controllers/reviewDeletionController.js
const Review = require('../models/Review');
const Product = require('../models/Product');

// @desc    Soft delete a review (user or admin)
// @route   DELETE /api/reviews/:id/soft
// @access  Private (owner or admin)
const softDeleteReview = async (req, res) => {
  try {
    const { id } = req.params;
    const { reason, comment } = req.body;
    const userId = req.user.id;
    const userRole = req.user.role;
    
    // Find review
    const review = await Review.findById(id);
    
    if (!review) {
      return res.status(404).json({
        success: false,
        message: 'Review not found'
      });
    }
    
    // Check authorization
    const isOwner = review.user.toString() === userId;
    const isAdmin = userRole === 'admin';
    
    if (!isOwner && !isAdmin) {
      return res.status(403).json({
        success: false,
        message: 'Not authorized to delete this review'
      });
    }
    
    // Check if already deleted
    if (review.isDeleted) {
      return res.status(400).json({
        success: false,
        message: 'Review is already deleted'
      });
    }
    
    // Perform soft delete
    await review.softDelete(
      userId, 
      isOwner ? 'user_request' : (reason || 'violation'),
      comment || (isOwner ? 'User requested deletion' : 'Removed by moderator')
    );
    
    res.status(200).json({
      success: true,
      message: 'Review deleted successfully',
      data: {
        id: review._id,
        isDeleted: review.isDeleted,
        deletedAt: review.deletedAt
      }
    });
    
  } catch (error) {
    res.status(500).json({
      success: false,
      message: error.message
    });
  }
};

// @desc    Restore a soft-deleted review
// @route   POST /api/reviews/:id/restore
// @access  Private (admin only)
const restoreReview = async (req, res) => {
  try {
    const { id } = req.params;
    const userId = req.user.id;
    
    // Find review (including deleted)
    const review = await Review.findWithDeleted().findById(id);
    
    if (!review) {
      return res.status(404).json({
        success: false,
        message: 'Review not found'
      });
    }
    
    // Check if actually deleted
    if (!review.isDeleted) {
      return res.status(400).json({
        success: false,
        message: 'Review is not deleted'
      });
    }
    
    // Check authorization (admin only)
    if (req.user.role !== 'admin') {
      return res.status(403).json({
        success: false,
        message: 'Only admins can restore reviews'
      });
    }
    
    // Restore review
    await review.restore(userId);
    
    res.status(200).json({
      success: true,
      message: 'Review restored successfully',
      data: review
    });
    
  } catch (error) {
    res.status(500).json({
      success: false,
      message: error.message
    });
  }
};

// @desc    Bulk soft delete reviews (admin)
// @route   POST /api/reviews/bulk/soft-delete
// @access  Private (admin only)
const bulkSoftDeleteReviews = async (req, res) => {
  try {
    const { reviewIds, reason, comment } = req.body;
    const userId = req.user.id;
    
    if (!reviewIds || !reviewIds.length) {
      return res.status(400).json({
        success: false,
        message: 'No review IDs provided'
      });
    }
    
    const results = {
      successful: [],
      failed: []
    };
    
    for (const reviewId of reviewIds) {
      try {
        const review = await Review.findById(reviewId);
        
        if (review && !review.isDeleted) {
          await review.softDelete(userId, reason, comment);
          results.successful.push(reviewId);
        } else {
          results.failed.push({ id: reviewId, reason: 'Review not found or already deleted' });
        }
      } catch (error) {
        results.failed.push({ id: reviewId, reason: error.message });
      }
    }
    
    res.status(200).json({
      success: true,
      message: `Deleted ${results.successful.length} reviews`,
      data: results
    });
    
  } catch (error) {
    res.status(500).json({
      success: false,
      message: error.message
    });
  }
};

// @desc    Get deleted reviews (admin)
// @route   GET /api/reviews/deleted
// @access  Private (admin only)
const getDeletedReviews = async (req, res) => {
  try {
    const { page = 1, limit = 20, sortBy = '-deletedAt' } = req.query;
    
    const pageNum = parseInt(page);
    const limitNum = parseInt(limit);
    const skip = (pageNum - 1) * limitNum;
    
    const reviews = await Review.findWithDeleted()
      .find({ isDeleted: true })
      .populate('user', 'name email')
      .populate('product', 'name')
      .populate('deletedBy', 'name email')
      .sort(sortBy)
      .limit(limitNum)
      .skip(skip);
    
    const total = await Review.findWithDeleted()
      .countDocuments({ isDeleted: true });
    
    res.status(200).json({
      success: true,
      data: reviews,
      pagination: {
        page: pageNum,
        limit: limitNum,
        total,
        pages: Math.ceil(total / limitNum)
      }
    });
    
  } catch (error) {
    res.status(500).json({
      success: false,
      message: error.message
    });
  }
};

// @desc    Auto-delete old reviews (cron job)
// @route   POST /api/reviews/auto-delete
// @access  Private (admin only / internal)
const autoDeleteOldReviews = async (req, res) => {
  try {
    const { daysOld = 365, reason = 'auto_cleanup' } = req.body;
    const cutoffDate = new Date();
    cutoffDate.setDate(cutoffDate.getDate() - daysOld);
    
    const oldReviews = await Review.find({
      createdAt: { $lt: cutoffDate },
      isDeleted: false,
      'helpfulVotes.count': { $lt: 2 } // Low engagement reviews
    });
    
    const results = [];
    for (const review of oldReviews) {
      await review.softDelete(
        req.user.id,
        reason,
        `Auto-deleted after ${daysOld} days with low engagement`
      );
      results.push(review._id);
    }
    
    res.status(200).json({
      success: true,
      message: `Auto-deleted ${results.length} old reviews`,
      data: { deletedCount: results.length, reviewIds: results }
    });
    
  } catch (error) {
    res.status(500).json({
      success: false,
      message: error.message
    });
  }
};

// @desc    Soft delete a listing (seller or admin)
// @route   DELETE /api/listings/:id/soft
// @access  Private (owner or admin)
const softDeleteListing = async (req, res) => {
  try {
    const { id } = req.params;
    const { reason, comment } = req.body;
    const userId = req.user.id;
    const userRole = req.user.role;
    
    // Find listing
    const listing = await Listing.findById(id);
    
    if (!listing) {
      return res.status(404).json({
        success: false,
        message: 'Listing not found'
      });
    }
    
    // Check authorization
    const isOwner = listing.seller.toString() === userId;
    const isAdmin = userRole === 'admin';
    
    if (!isOwner && !isAdmin) {
      return res.status(403).json({
        success: false,
        message: 'Not authorized to delete this listing'
      });
    }
    
    // Check if already deleted
    if (listing.isDeleted) {
      return res.status(400).json({
        success: false,
        message: 'Listing is already deleted'
      });
    }
    
    // Check if listing has active orders
    const hasActiveOrders = await Order.findOne({
      'items.listing': id,
      status: { $in: ['pending', 'processing', 'shipped'] }
    });
    
    if (hasActiveOrders) {
      return res.status(400).json({
        success: false,
        message: 'Cannot delete listing with active orders'
      });
    }
    
    // Perform soft delete
    await listing.softDelete(
      userId,
      isOwner ? 'seller_request' : (reason || 'violation'),
      comment || (isOwner ? 'Seller removed listing' : 'Removed by admin')
    );
    
    // Update seller stats
    await User.findByIdAndUpdate(userId, {
      $inc: { totalListingsDeleted: 1 }
    });
    
    res.status(200).json({
      success: true,
      message: 'Listing deleted successfully',
      data: {
        id: listing._id,
        title: listing.title,
        isDeleted: listing.isDeleted,
        deletedAt: listing.deletedAt,
        willBePermanentlyDeleted: listing.softDeleteExpiry
      }
    });
    
  } catch (error) {
    console.error('Soft delete error:', error);
    res.status(500).json({
      success: false,
      message: error.message
    });
  }
};

// Helper function
async function calculateAverageRestoreTime(startDate) {
  const Listing = require('../models/Listing');
  const restoredListings = await Listing.findWithDeleted()
    .find({
      restoredAt: { $ne: null },
      deletedAt: { $gte: startDate }
    });
  
  if (restoredListings.length === 0) return 0;
  
  const totalTime = restoredListings.reduce((sum, listing) => {
    return sum + (listing.restoredAt - listing.deletedAt);
  }, 0);
  
  return totalTime / restoredListings.length / (1000 * 60 * 60 * 24); // in days
}

  const [isDeleting, setIsDeleting] = useState(false);
  const [understood, setUnderstood] = useState(false);
  
  const reasons = [
    { value: 'seller_request', label: 'I want to remove my listing' },
    { value: 'sold_out', label: 'Item is sold out' },
    { value: 'expired', label: 'Listing expired' },
    { value: 'duplicate', label: 'Duplicate listing' },
    { value: 'inaccurate', label: 'Listing has inaccurate information' },
    { value: 'other', label: 'Other reason' }
  ];
  
  const handleSubmit = async () => {
    if (!reason) {
      alert('Please select a reason for deletion');
      return;
    }
    
    if (!understood) {
      alert('Please confirm you understand the consequences');
      return;
    }
    
    setIsDeleting(true);
    try {
      await onConfirm(listing._id, reason, comment);
    } finally {
      setIsDeleting(false);
    }
  };
  
  return (
    <div className="delete-modal-overlay">
      <div className="delete-modal">
        <div className="delete-modal-header">
          <div className="delete-icon">
            <AlertTriangle size={24} />
          </div>
          <h2>Delete Listing</h2>
          <button className="close-btn" onClick={onClose}>
            <X size={20} />
          </button>
        </div>
        
        <div className="delete-modal-body">
          {/* Listing Preview */}
          <div className="listing-preview">
            <img 
              src={listing.images?.[0]?.url || '/placeholder.jpg'} 
              alt={listing.title}
              className="preview-image"
            />
            <div className="preview-info">
              <h4>{listing.title}</h4>
              <div className="listing-stats">
                <span><Eye size={14} /> {listing.views || 0} views</span>
                <span><Heart size={14} /> {listing.favoritesCount || 0} saves</span>
              </div>
              <div className="listing-price">${listing.price}</div>
            </div>
          </div>
          
          {/* Warning Messages */}
          <div className="warning-box">
            <h4>⚠️ Before you delete:</h4>
            <ul>
              <li>This action cannot be undone</li>
              <li>All associated data will be removed</li>
              <li>Potential buyers will no longer see this listing</li>
              {listing.hasActiveOrders && (
                <li className="error">⚠️ This listing has active orders</li>
              )}
            </ul>
          </div>
          
          {/* Reason Selection */}
          <div className="form-group">
            <label>Reason for deletion *</label>
            <select 
              value={reason} 
              onChange={(e) => setReason(e.target.value)}
              className="reason-select"
            >
              <option value="">Select a reason</option>
              {reasons.map(r => (
                <option key={r.value} value={r.value}>{r.label}</option>
              ))}
            </select>
          </div>
          
          {/* Additional Comments */}
          <div className="form-group">
            <label>Additional comments (optional)</label>
            <textarea
              value={comment}
              onChange={(e) => setComment(e.target.value)}
              placeholder="Please provide any additional details..."
              rows={3}
            />
          </div>
          
          {/* Confirmation Checkbox */}
          <label className="confirmation-checkbox">
            <input
              type="checkbox"
              checked={understood}
              onChange={(e) => setUnderstood(e.target.checked)}
            />
            <span>I understand that this action is permanent and cannot be undone</span>
          </label>
          
          {/* Recovery Info */}
          {reason === 'seller_request' && (
            <div className="info-message">
              <Calendar size={16} />
              <span>You can restore this listing within 30 days from your deleted listings page</span>
            </div>
          )}
        </div>
        
        <div className="delete-modal-footer">
          <button className="cancel-btn" onClick={onClose}>
            Cancel
          </button>
          <button 
            className="delete-btn" 
            onClick={handleSubmit}
            disabled={isDeleting || !reason || !understood || listing.hasActiveOrders}
          >
            {isDeleting ? 'Deleting...' : 'Yes, Delete Listing'}
          </button>
        </div>
      </div>
    </div>
  );
};

export default DeleteListingModal;
