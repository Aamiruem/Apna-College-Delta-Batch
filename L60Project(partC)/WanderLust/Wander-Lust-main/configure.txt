Configuring Strategy in Passport.js (MERN / Express Authentication)
In Passport.js, a strategy means how users will log in.

Examples:

Local Strategy → username/password

Google Strategy → Google login

GitHub Strategy → GitHub login

Most beginners start with:

passport-local
1. Install Packages
npm install passport passport-local passport-local-mongoose
2. User Schema Setup
models/user.js
const mongoose = require("mongoose");
const Schema = mongoose.Schema;

const passportLocalMongoose = require("passport-local-mongoose");

const userSchema = new Schema({
    email: {
        type: String,
        required: true,
    },
});

userSchema.plugin(passportLocalMongoose);

module.exports = mongoose.model("User", userSchema);
What passport-local-mongoose Does
It automatically adds:

username field

hashed password

authentication methods

Methods added:

User.register()
User.authenticate()
User.serializeUser()
User.deserializeUser()
3. Configure Passport
app.js
const express = require("express");
const app = express();

const session = require("express-session");
const passport = require("passport");
const LocalStrategy = require("passport-local");

const User = require("./models/user");
4. Configure Session
app.use(session({
    secret: "mysupersecretcode",
    resave: false,
    saveUninitialized: true,
}));
5. Initialize Passport
app.use(passport.initialize());
app.use(passport.session());
6. Configure Strategy
THIS is called Configuring Strategy 👇

passport.use(
    new LocalStrategy(User.authenticate())
);
How It Works
LocalStrategy() checks:

username

password

User.authenticate() comes from:

passport-local-mongoose
It automatically compares:

entered password

hashed password in database

7. Serialize User
passport.serializeUser(User.serializeUser());
passport.deserializeUser(User.deserializeUser());
Meaning
serializeUser()
Stores user ID into session.

Example:

req.session.passport = {
   user: "6874abc123"
}
deserializeUser()
Gets full user data from database using stored ID.

Complete Passport Configuration
const session = require("express-session");
const passport = require("passport");
const LocalStrategy = require("passport-local");
const User = require("./models/user");

app.use(session({
    secret: "mysupersecret",
    resave: false,
    saveUninitialized: true,
}));

app.use(passport.initialize());
app.use(passport.session());

passport.use(
    new LocalStrategy(User.authenticate())
);

passport.serializeUser(User.serializeUser());

passport.deserializeUser(User.deserializeUser());

Common Errors
Error:
Failed to serialize user into session
Fix:
passport.serializeUser(User.serializeUser());
passport.deserializeUser(User.deserializeUser());
Error:
passport.initialize() middleware not in use
Fix:
app.use(passport.initialize());
Error:
Login sessions require session support
Fix:
Session middleware must come BEFORE passport session.

app.use(session({...}));

app.use(passport.initialize());

Demo User in Authentication Project
A Demo User is a temporary/sample user account used for:

testing login

checking authentication

showing project functionality

avoiding repeated signup

Example:

Username: demoUser
Password: demo123
Why Use Demo User?
Suppose you made:

Airbnb Clone

Social Media App

MERN Dashboard

You may want recruiters/users to test login quickly.

So you create a demo account.

Method 1 — Create Demo User Manually
Route Example
app.get("/demouser", async(req, res) => {

    let fakeUser = new User({
        email: "demo@gmail.com",
        username: "demoUser",
    });

    let registeredUser = await User.register(
        fakeUser,
        "demo123"
    );

    res.send(registeredUser);

});
What Happens Here?
Step 1
Create user object:

let fakeUser = new User({
    email: "demo@gmail.com",
    username: "demoUser",
});
Step 2
Register user:

User.register(fakeUser, "demo123");
This automatically:

hashes password

stores user in DB

Database Output
{
   username: "demoUser",
   email: "demo@gmail.com",
   hash: "...",
   salt: "..."
}
Password is NOT stored directly.

Important
Run this route ONLY once.

Otherwise MongoDB gives:

UserExistsError
because username already exists.

Better Way (Recommended)
Use try-catch.

app.get("/demouser", async(req, res) => {

    try {

        let fakeUser = new User({
            email: "demo@gmail.com",
            username: "demoUser",
        });

        let registeredUser = await User.register(
            fakeUser,
            "demo123"
        );

        res.send(registeredUser);

    } catch(err) {

        res.send(err.message);

    }

});
Login with Demo User
Username: demoUser
Password: demo123
Auto Login Demo User
You can directly log in demo user.

app.get("/login-demo", (req, res, next) => {

    let fakeUser = {
        username: "demoUser",
        password: "demo123"
    };

    req.login(fakeUser, (err) => {

        if(err) {
            return next(err);
        }

        res.redirect("/listings");

    });

});
Understanding req.login()
req.login() creates login session manually.

Normally Passport does:

Form Submit
   ↓
passport.authenticate()
   ↓
Login
But req.login() skips form submission.

Demo User Flow
Create Demo User
       ↓
Store in Database
       ↓
Login using Passport
       ↓
Session Created
       ↓
Access Protected Routes
Protected Route Example
const isLoggedIn = (req, res, next) => {

    if(!req.isAuthenticated()) {
        return res.redirect("/login");
    }

    next();
};
Use:

app.get("/profile", isLoggedIn, (req, res) => {
    res.send("Welcome");
});

Signup User POST Route in Express + Passport
A signup POST route is used to:

receive form data

create new user

hash password

save user in database

Complete Signup POST Route
app.post("/signup", async(req, res, next) => {

    try {

        let { username, email, password } = req.body;

        const newUser = new User({
            email,
            username,
        });

        const registeredUser = await User.register(
            newUser,
            password
        );

        req.login(registeredUser, (err) => {

            if(err) {
                return next(err);
            }

            res.redirect("/listings");

        });

    } catch(err) {

        res.send(err.message);

    }

});

Login means:

Passport.js handles this using:

Login Route
app.post("/login",
    passport.authenticate("local", {
        failureRedirect: "/login",
    }),
    async(req, res) => {

        res.redirect("/listings");

});
How This Works
Step 1 — User Submit Form
username + password
goes to:

POST /login
Step 2 — Passport Authenticate
passport.authenticate("local")
uses:

LocalStrategy

User.authenticate()

to verify user.

Local Strategy Configuration
passport.use(
    new LocalStrategy(User.authenticate())
);
What Passport Checks
Passport compares:

Entered Password
        VS
Stored Hashed Password
If Login Success
Passport:

creates session

stores user ID

logs user in

Example:

req.session.passport = {
   user: "687abc123"
}
If Login Fails
Redirects:

failureRedirect: "/login"
Complete Login Example
