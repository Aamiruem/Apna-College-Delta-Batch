init command

Here’s a simple and clear explanation of the git init command 🚀

🔹 What is git init?

👉 git init is used to start Git tracking in a project folder

📌 It converts a normal folder into a Git repository

🔰 Syntax
git init
🧠 What happens internally?

When you run git init:

A hidden folder named .git is created

Git starts tracking changes in that folder

Your Project Folder
   └── .git (hidden folder)

📌 This .git folder stores:

Commit history

Branches

Configuration

📁 Example
Step 1: Create folder
mkdir my-project
cd my-project
Step 2: Initialize Git
git init

👉 Output:

Initialized empty Git repository
🔁 What to do after git init?
git add .
git commit -m "first commit"

👉 Now your project is tracked by Git

🔗 Connect to GitHub

To upload to GitHub:

git remote add origin <repo-url>
git push -u origin main
🎯 When to Use git init?

Starting a new project

Adding Git to an existing project

⚠️ Common Mistakes

❌ Running git init inside wrong folder
❌ Running it multiple times unnecessarily
❌ Forgetting to add files after init

🚀 Pro Tips

Run git status after git init

Use .gitignore to ignore unwanted files

Initialize once per project
