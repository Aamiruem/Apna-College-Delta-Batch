Here’s a complete guide to configuring Git (step-by-step) ⚙️🚀
This is the first thing every developer must do before using Git.

🔹 1. Check if Git is Installed
git --version

📌 If installed → shows version
📌 If not → download and install Git

🔰 2. Basic Configuration (VERY IMPORTANT)
👉 Set your name
git config --global user.name "Your Name"
👉 Set your email
git config --global user.email "your@email.com"

📌 These appear in every commit you make

🔍 3. Check Configuration
git config --list

📌 Shows all current settings

🌍 4. Global vs Local Config
👉 Global (for all projects)
git config --global user.name "Aamir"
👉 Local (only for one project)
git config user.name "Project Name"

📌 Local overrides global

📝 5. Set Default Editor
git config --global core.editor "code --wait"

📌 Opens VS Code for commit messages

🌿 6. Set Default Branch Name
git config --global init.defaultBranch main

📌 Now every repo starts with main (instead of master)

🎨 7. Enable Color Output
git config --global color.ui auto

📌 Makes terminal output easier to read

🔐 8. Configure Credential Helper (IMPORTANT)
👉 Save login credentials
git config --global credential.helper store

📌 Saves username/password (or token)

👉 For Windows (recommended)
git config --global credential.helper manager

📌 Uses secure Git Credential Manager

🔑 9. Authentication with GitHub

For GitHub, password is NOT used ❌

👉 Use:

Personal Access Token (PAT)

🔐 10. SSH Configuration (Advanced but Best)
👉 Generate SSH key
ssh-keygen -t ed25519 -C "your@email.com"
👉 Start SSH agent
eval "$(ssh-agent -s)"
👉 Add key
ssh-add ~/.ssh/id_ed25519
👉 Copy key
cat ~/.ssh/id_ed25519.pub

👉 Paste this into GitHub → SSH Keys

📌 Now you can push without password

📂 11. View Specific Config
git config user.name
git config user.email
❌ 12. Remove Config
git config --global --unset user.name
🔄 13. Edit Config File Directly
git config --global --edit

📌 Opens config file in editor

🎯 14. Best Configuration (Recommended Setup)
git config --global user.name "Aamir Hussain Azad"
git config --global user.email "your@email.com"
git config --global core.editor "code --wait"
git config --global init.defaultBranch main
git config --global credential.helper manager
git config --global color.ui auto
🚀 Final Understanding

👉 Git configuration controls:

Your identity

Editor

Authentication

Default behavior

💡 Pro Tips

Always use correct email (same as GitHub)

Use SSH for easier login

Use global config for simplicity

Verify with git config --list
