🧱 LEVEL 1 — BASICS
📦 What is the Box Model?

Every HTML element = a box

It has 4 parts:

Content

Padding

Border

Margin

Margin → Border → Padding → Content

🔹 Content

Actual text/image inside the element.

div { width: 200px; height: 100px; }

🔹 Padding (inside space)

Space between content and border.

div { padding: 20px; }

🔹 Border

Line around padding + content.

div { border: 2px solid black; }

🔹 Margin (outside space)

Space outside the element.

div { margin: 30px; }

🧮 LEVEL 2 — SIZE CALCULATION
Default box-sizing: content-box
div {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}


👉 Total width =
200 + 40 (padding) + 10 (border) = 250px

🔁 box-sizing: border-box (BEST PRACTICE)
* {
  box-sizing: border-box;
}


✔ Width includes padding + border
✔ Layout becomes easy

🎯 LEVEL 3 — SHORTCUTS & CONTROL
Padding & Margin Shorthand
padding: 10px;                /* all sides */
padding: 10px 20px;          /* top-bottom | left-right */
padding: 10px 20px 5px 15px; /* top right bottom left */


Same for margin 👆

Individual Sides
margin-top: 10px;
padding-left: 20px;
border-bottom: 3px solid red;

⚠ LEVEL 4 — BEHAVIOR & EDGE CASES
🧷 Inline vs Block
Type	Width/Height	Padding/Border	Margin
block	✅	✅	✅
inline	❌	⚠ (L/R only)	⚠
inline-block	✅	✅	✅
🔄 Margin Collapsing

Vertical margins collapse:

p { margin: 20px 0; }


Two <p> together → margin = 20px, not 40px

🚫 Negative Margin
div {
  margin-top: -20px;
}


👉 Pulls element upward

🧠 LEVEL 5 — ADVANCED CONCEPTS
🔹 Box Model + Display
span {
  display: inline-block;
  width: 100px;
  padding: 10px;
}

🔹 Box Model + Flex/Grid

In layouts:

.card {
  width: 300px;
  padding: 20px;
  box-sizing: border-box;
}


👉 Prevents overflow in cards / columns

🔹 Overflow Control
div {
  overflow: hidden;
}


Options:

hidden

scroll

auto

🔹 Outline vs Border
div {
  outline: 2px solid red;
}


✔ Doesn’t affect box size
❌ Border does

🎓 LEVEL 6 — REAL-WORLD CARD EXAMPLE
.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #333;
  margin: 20px;
  box-sizing: border-box;
  border-radius: 10px;
}


Used in:
✔ Blog cards
✔ Product cards
✔ Dashboard widgets
