ID Selectors
ID selectors target elements based on their id attribute. They're the most specific single selectors in CSS.

Basic Syntax
css
#id-name {
  /* styles applied to element with id="id-name" */
}
Examples
html
<div id="header">Header Content</div>
<section id="main-content">Main Content</section>
<button id="submit-btn">Submit</button>
css
#header {
  background-color: #333;
  color: white;
  padding: 20px;
}

#main-content {
  max-width: 1200px;
  margin: 0 auto;
  padding: 2rem;
}

#submit-btn {
  background-color: #007bff;
  color: white;
  padding: 12px 24px;
  border-radius: 4px;
}
Key Characteristics
1. High Specificity (0,1,0,0)
css
/* Specificity battle */
p {
  color: black;        /* 0,0,0,1 */
}

.paragraph {
  color: blue;         /* 0,0,1,0 */
}

#special-paragraph {
  color: red;          /* 0,1,0,0 - WINS! */
}

#special-paragraph.paragraph {
  color: purple;       /* 0,1,1,0 - WINS even more! */
}
2. Should Be Unique
html
<!-- CORRECT: Unique IDs -->
<div id="header"></div>
<div id="main"></div>
<div id="footer"></div>

<!-- INCORRECT: Duplicate IDs (invalid HTML) -->
<div id="section"></div>
<div id="section"></div> <!-- ❌ Avoid this -->
Common Use Cases
1. Page Layout Sections
css
#page-container {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}

#header {
  position: sticky;
  top: 0;
  z-index: 1000;
}

#main-content {
  flex: 1;
  padding: 2rem;
}

#footer {
  margin-top: auto;
  background-color: #f8f9fa;
  padding: 1rem;
}
2. Unique Interactive Elements
css
#login-modal {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  z-index: 1000;
}

#scroll-to-top {
  position: fixed;
  bottom: 20px;
  right: 20px;
  display: none;
}

#cookie-banner {
  position: fixed;
  bottom: 0;
  width: 100%;
  background: #333;
  color: white;
  padding: 1rem;
}
3. JavaScript Hooks
html
<button id="toggle-menu">Menu</button>
<div id="sidebar">Navigation</div>
<input id="search-input" type="text">
<div id="search-results"></div>
css
/* Style elements that will be manipulated by JS */
#sidebar {
  transform: translateX(-100%);
  transition: transform 0.3s ease;
}

#sidebar.open {
  transform: translateX(0);
}

#search-input:focus {
  outline: 2px solid #007bff;
}
Best Practices
1. Use Sparingly in CSS
css
/* ❌ Avoid styling primarily with IDs */
#header nav ul li a {
  color: blue; /* Too specific, hard to override */
}

/* ✅ Better: Use classes for styling */
.main-navigation a {
  color: blue;
}

/* ✅ Use ID for unique positioning/layout */
#site-header {
  position: sticky;
  top: 0;
}
2. Combine with Other Selectors Carefully
css
/* ❌ Overly specific */
body #main #content .article #title {
  font-size: 2rem; /* Impossible to override */
}

/* ✅ Keep it reasonable */
#main-title {
  font-size: 2rem;
}

/* ✅ Even better with a class */
.title-large {
  font-size: 2rem;
}
3. Use for JavaScript, Style with Classes
html
<!-- Good pattern -->
<button id="user-menu-button" class="btn btn-primary">
  User Menu
</button>

<div id="user-menu-dropdown" class="dropdown hidden">
  <!-- dropdown content -->
</div>
css
/* Style with classes */
.btn-primary {
  background-color: #007bff;
}

.dropdown {
  position: absolute;
  top: 100%;
  right: 0;
}

.hidden {
  display: none;
}
Specificity Issues
The Specificity Problem
css
/* In your CSS */
#content .text {
  color: blue; /* 0,1,1,0 */
}

/* Later, you want to change it */
.text.warning {
  color: orange; /* 0,0,2,0 - Loses! */
}

/* Have to use !important or more specific selector */
.text.warning {
  color: orange !important; /* Now works, but messy */
}
Better Approach
css
/* Use classes with BEM or similar methodology */
.content__text {
  color: blue;
}

.content__text--warning {
  color: orange; /* Easy to override */
}
Performance
Fast: Browsers can find elements by ID quickly using getElementById

But specificity can lead to performance issues in CSS calculation

css
/* ❌ Slow: Browser checks all divs */
div #very-specific-element {
  /* styles */
}

/* ✅ Fast: Direct ID reference */
#very-specific-element {
  /* styles */
}
Accessibility Connection
IDs are crucial for accessibility:

html
<button id="menu-button" aria-expanded="false" aria-controls="menu">
  Open Menu
</button>

<nav id="menu" aria-labelledby="menu-button" hidden>
  <!-- Menu content -->
</nav>
css
#menu-button[aria-expanded="true"] {
  background-color: #e0e0e0;
}

#menu:not([hidden]) {
  display: block;
}
Modern CSS Alternatives
CSS Custom Properties with IDs
css
#theme-settings {
  --primary-color: #007bff;
  --spacing-unit: 1rem;
}

/* Use the variables elsewhere */
.header {
  background-color: var(--primary-color);
  padding: var(--spacing-unit);
}
Data Attributes Instead
html
<div data-component="modal" data-modal-id="user-settings">
  <!-- Modal content -->
</div>
css
[data-component="modal"] {
  position: fixed;
  z-index: 1000;
}

[data-modal-id="user-settings"] {
  width: 90%;
  max-width: 500px;
}
When to Use ID Selectors
✅ Appropriate Uses:
Page layout containers (#header, #main, #footer)

Unique interactive elements managed by JavaScript

Anchor links for page navigation

Form elements with specific functionality

Accessibility relationships (aria-labelledby, aria-describedby)

❌ Avoid For:
General styling (use classes instead)

Component styling in component-based frameworks

Styles that might need to be reused or overridden

Styling multiple elements

Summary Table
Aspect	ID Selectors	Class Selectors
Syntax	#id	.class
Specificity	0,1,0,0 (High)	0,0,1,0 (Medium)
Uniqueness	Must be unique	Can be reused
Use Case	Unique elements, JS hooks	Reusable styles, components
Performance	Very fast	Fast
Maintainability	Low (creates specificity wars)	High
The Modern Consensus
css
/* ❌ Old school: IDs for styling */
#main-nav {
  background: #333;
  color: white;
}

#main-nav li {
  display: inline-block;
}

/* ✅ Modern approach: IDs for hooks, classes for styling */
<nav id="main-navigation" class="navbar navbar-dark">
  <ul class="navbar__list">
    <li class="navbar__item"></li>
  </ul>
</nav>

.navbar {
  background: #333;
}

.navbar-dark {
  color: white;
}
Best Practice: Use ID selectors primarily for JavaScript functionality and accessibility, while using class selectors for styling. This keeps your CSS maintainable and avoids specificity conflicts.
