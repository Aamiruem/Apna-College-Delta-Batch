🌿 CSS Descendant Selector — Complete Concept
🧩 What is Descendant Selector?

The descendant selector selects all elements inside another element, no matter how deeply they are nested.

🧪 Syntax
ancestor descendant {
  property: value;
}

🧪 Example 1 — Basic
<div>
  <p>Paragraph 1</p>
  <section>
    <p>Paragraph 2</p>
  </section>
</div>

div p {
  color: red;
}


✔ Paragraph 1 → Red
✔ Paragraph 2 → Red
(because both are inside div)

🧪 Example 2 — Real Website (Blog)
<article class="post">
  <h2>Title</h2>
  <p>Intro text</p>
  <div>
    <p>More content</p>
  </div>
</article>

.post p {
  font-size: 18px;
}


✔ All paragraphs inside .post get styled

🧪 Example 3 — Navigation Menu
<nav>
  <ul>
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
  </ul>
</nav>

nav a {
  color: blue;
}


✔ All links inside nav turn blue

🧠 Descendant vs Child
Selector	Meaning
div p	All p inside div
div > p	Only direct p children
🎯 Why Descendant Selector is Important

✔ Very flexible
✔ Reduces number of classes
✔ Easy to write
✔ Used in almost every website

🧾 Interview Questions

Q: How many levels deep does descendant selector work?
→ Unlimited

Q: Is it faster than child selector?
→ No — child selector is faster
