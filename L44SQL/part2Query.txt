🔹 1. What is WHERE Clause?
The WHERE clause is used in SQL to filter data (i.e., select only specific rows from a table).

👉 Without WHERE → you get all data
👉 With WHERE → you get filtered data

🔹 2. Basic Syntax
SELECT column1, column2
FROM table_name
WHERE condition;

🔹 1. Comparison Operators
Used to compare values.

Operator	Meaning
=	Equal
!= / <>	Not equal
>	Greater than
<	Less than
>=	Greater than or equal
<=	Less than or equal
✅ Examples
SELECT * FROM students WHERE marks = 85;
SELECT * FROM students WHERE age > 20;

🔹 2. Logical Operators
Used to combine multiple conditions.

✅ AND (both true)
SELECT * FROM students
WHERE city = 'Delhi' AND marks > 80;
✅ OR (any one true)
SELECT * FROM students
WHERE city = 'Delhi' OR city = 'Mumbai';
✅ NOT (reverse condition)
SELECT * FROM students
WHERE NOT city = 'Delhi';
🔹 3. BETWEEN
Used for range values.

SELECT * FROM students
WHERE marks BETWEEN 70 AND 90;
👉 Includes 70 and 90

🔹 4. IN Operator
Used to match multiple values.

SELECT * FROM students
WHERE city IN ('Delhi', 'Mumbai', 'Pune');
🔹 5. LIKE Operator (Pattern Matching)
Symbol	Meaning
%	Any number of characters
_	Single character
✅ Examples
SELECT * FROM students WHERE name LIKE 'A%';
👉 Starts with A

SELECT * FROM students WHERE name LIKE '%a';
👉 Ends with a

SELECT * FROM students WHERE name LIKE '_a%';
👉 Second letter is 'a'

🔹 6. IS NULL / IS NOT NULL
Used to check missing values.

SELECT * FROM students WHERE marks IS NULL;
SELECT * FROM students WHERE marks IS NOT NULL;
🔹 7. EXISTS
Checks if subquery returns data.

SELECT * FROM students s
WHERE EXISTS (
    SELECT 1 FROM enrollments e
    WHERE e.student_id = s.id
);
🔹 8. ANY
Condition true if any value matches

SELECT * FROM students
WHERE marks > ANY (
    SELECT marks FROM students WHERE city = 'Delhi'
);
🔹 9. ALL
Condition true if all values match

SELECT * FROM students
WHERE marks > ALL (
    SELECT marks FROM students WHERE city = 'Delhi'
);
🔹 10. NOT IN
SELECT * FROM students
WHERE city NOT IN ('Delhi', 'Mumbai');

🔥 WHERE Clause + Operators (Complete Notes)
The WHERE clause is used to filter rows based on conditions.

SELECT * FROM table_name
WHERE condition;
🔹 1. Arithmetic Operators
Used for calculations inside conditions.

Operator	Meaning
+	Addition
-	Subtraction
*	Multiplication
/	Division
%	Modulus (remainder)
✅ Examples
SELECT * FROM students
WHERE marks + 5 > 90;
SELECT * FROM students
WHERE marks % 2 = 0;
👉 Used less in filtering, but important in logic questions.

🔹 2. Comparison Operators
Used to compare values.

Operator	Meaning
=	Equal
!= / <>	Not equal
>	Greater than
<	Less than
>=	Greater or equal
<=	Less or equal
✅ Examples

Feature	WHERE	HAVING

SELECT city, AVG(marks)
FROM students
GROUP BY city
HAVING AVG(marks) > 80;

FROM students
WHERE marks > 60
GROUP BY city
HAVING AVG(marks) > 80;

FROM students

FROM students
