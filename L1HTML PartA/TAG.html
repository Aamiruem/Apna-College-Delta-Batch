Document Structure

<!DOCTYPE>
Defines the document type and version of HTML.
<!DOCTYPE html>
<html>
The root element of an HTML page.
<html lang="en">...</html>
<head>
Contains meta information about the document.
<head>
  <title>Page Title</title>
</head>
<body>
Contains the visible page content.
<body>
  <h1>My Heading</h1>
  <p>My paragraph.</p>
</body>

Metadata

<title>
Defines the title of the document (shown in browser tab).
<title>My Web Page</title>
<meta>
Defines metadata about an HTML document.
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<link>
Defines the relationship between a document and an external resource.
<link rel="stylesheet" href="styles.css">

Headings

<h1> to <h6>
Define HTML headings from most important (h1) to least important (h6).
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>

Text Formatting

<p>
Defines a paragraph.
<p>This is a paragraph.</p>
<strong>
Defines important text (typically displayed in bold).
<strong>This text is important!</strong>
<em>
Defines emphasized text (typically displayed in italic).
<em>This text is emphasized.</em>
<span>
An inline container used to mark up a part of a text.
My mother has <span style="color:blue">blue</span> eyes.

Lists

<ul>
Defines an unordered (bulleted) list.
<ul>
  <li>Coffee</li>
  <li>Tea</li>
</ul>
<ol>
Defines an ordered (numbered) list.
<ol>
  <li>First item</li>
  <li>Second item</li>
</ol>

Images

<img>
Embeds an image in an HTML page.
<img src="image.jpg" alt="Description of image">

Audio & Video

<audio>
Embeds sound content in a document.
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>
<video>
Embeds video content in a document.
<video width="320" height="240" controls>
  <source src="movie.mp4" type="video/mp4">
</video>

Form Elements

<form>
Defines an HTML form for user input.
<form action="/submit" method="post">
  <!-- form elements -->
</form>
<input>
Defines an input control (many types available).
<input type="text" name="username" placeholder="Enter username">
<input type="password" name="password">
<input type="email" name="email">
<textarea>
Defines a multi-line text input control.
<textarea rows="4" cols="50">
  Enter text here...
</textarea>
<button>
Defines a clickable button.
<button type="submit">Submit</button>

Semantic Elements

<header>
Represents introductory content or a set of navigational links.
<header>
  <h1>Website Title</h1>
  <nav>...</nav>
</header>
<nav>
Defines a set of navigation links.
<nav>
  <a href="/home">Home</a>
  <a href="/about">About</a>
</nav>
<main>
Specifies the main content of a document.
<main>
  <h1>Main Heading</h1>
  <p>Main content...</p>
</main>
<footer>
Defines a footer for a document or section.
<footer>
  <p>Copyright 2023</p>
</footer>
