Media Tags
<img>
Embeds an image in the document.
<img src="image.jpg" alt="Description" width="300" height="200">
<audio>
Embeds sound content in the document.
<audio controls><source src="audio.mp3" type="audio/mpeg"></audio>
<video>
Embeds video content in the document.
<video width="320" height="240" controls><source src="movie.mp4" type="video/mp4"></video>
<figure> and <figcaption>
Represents self-contained content with an optional caption.
Form Tags
<form>
Defines an HTML form for user input.
<form action="/submit" method="post">...</form>
<input>
Defines an input control with various types (text, password, checkbox, radio, etc.).











<textarea>
Defines a multi-line text input control.
<select> and <option>
Defines a drop-down list.
<button>
Defines a clickable button.
<label>
Defines a label for an input element.

Defines an HTML table.
