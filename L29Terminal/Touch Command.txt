touch Command (Create Files)

The touch command is used in the terminal to create a new empty file.
It is commonly used in shells like Bash and Z shell, which you can run in terminals such as Windows Terminal or Git Bash.

1. Basic Syntax
touch filename

Example:

touch index.js

This creates a new empty file named index.js in the current directory.

2. Example

Step 1: Check files

ls

Output example:

project
app.js

Step 2: Create a file

touch style.css

Step 3: Check again

ls

Output:

project
app.js
style.css
3. Create Multiple Files

You can create multiple files at once.

touch index.html style.css script.js

Files created:

index.html
style.css
script.js
4. Create File in Another Directory

Example:

touch project/app.js

This creates app.js inside the project folder.

5. Example Workflow (Developer)

When starting a web project:

mkdir myproject
cd myproject
touch index.html style.css script.js

Folder structure becomes:

myproject
 ├── index.html
 ├── style.css
 └── script.js
6. Important Note

If the file already exists, touch will not delete it.
Instead, it updates the file timestamp (last modified time).

7. Summary
Command	Purpose
touch file.txt	Create a new file
touch file1 file2	Create multiple files
touch folder/file.txt	Create file in folder

You are running the command in PowerShell, and the error occurs because touch is not a built-in command in PowerShell.
The touch command exists in Linux shells like Bash, which you get in Git Bash or Linux/macOS terminals.

So PowerShell shows this error:

touch : The term 'touch' is not recognized
How to Create a File in PowerShell

Instead of touch, use the PowerShell command:

1. New-Item
New-Item app.js

or

New-Item app.js -ItemType File

Result:

app.js

is created in your current folder.

Check the File

Run:

dir

You will see:

app.js
Another Short Method

PowerShell also allows:

ni app.js

ni = shortcut for New-Item.

If You Want to Use touch

You need a Linux-style terminal like Git Bash.

Example in Git Bash:

touch app.js

This will work.
